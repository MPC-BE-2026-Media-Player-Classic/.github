# Project Overview

MPC-BE (Media Player Classic – Black Edition) is a free and open-source multimedia player for Windows. It is based on the classic Media Player Classic interface and provides modern video and audio playback capabilities while maintaining a lightweight desktop design.

The player supports a wide range of media formats and includes built-in codecs, subtitle support, hardware-accelerated video decoding, customizable playback controls, and extensive configuration options.

MPC-BE is designed for users who want a traditional Windows media-player interface without the overhead of a large media-center application.

---

# Video & Audio Playback

MPC-BE can play common video and audio formats using its integrated media-processing components.

Supported media can include:

* MP4
* MKV
* AVI
* MOV
* WebM
* MPEG
* FLV
* MP3
* FLAC
* WAV
* OGG
* AAC

Actual format and codec compatibility depends on the current MPC-BE build and its included components.

The player also supports playlists, playback queues, fullscreen mode, frame stepping, playback speed control, and other standard media-player functions.

---

# Hardware Acceleration

MPC-BE supports hardware-accelerated video decoding through compatible Windows graphics hardware.

Depending on the GPU, driver, codec, and selected renderer, supported acceleration technologies can reduce CPU usage during playback of high-resolution video.

Hardware acceleration is particularly useful for demanding content such as high-bitrate 4K video and modern codecs.

The available options can be configured through MPC-BE's playback and decoder settings.

---

# Subtitles & Audio

MPC-BE includes subtitle support with configuration options for appearance, positioning, timing, and related playback behavior.

Multiple audio tracks can be selected when they are available within a media file.

The player also provides audio-processing and playback configuration options that allow users to adapt playback to different hardware and listening environments.

---

# Customization & Playback Controls

MPC-BE retains the familiar Media Player Classic-style interface while providing extensive configuration options.

Users can customize:

* Keyboard shortcuts
* Mouse controls
* Playback behavior
* Video renderer
* Audio output
* Subtitle appearance
* Toolbar elements
* Interface settings
* Hardware acceleration
* File associations

The application can therefore be configured for simple playback or more advanced media workflows.
